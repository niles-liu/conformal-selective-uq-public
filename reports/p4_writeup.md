# Selective conformal regression with conditional coverage under shift —
## validated against a known irreducible-noise floor

**Niles Liu · 2026-06-30 · public-safe note (the P4 interview artifact)**

> A portable uncertainty-quantification method: a pre-registered selective conformal regressor that
> (a) holds **group-conditional coverage under a documented distribution shift** and (b) is
> **mechanism-validated** — on a task with a *known* recoverable-vs-irreducible decomposition, the
> region it abstains from coincides with the genuinely-irreducible signal. Laptop-runnable, no API
> key, every number reproduces from a seeded run. Full plan: [`SPEC.md`](../SPEC.md); per-phase
> pre-registration + results in [`reports/`](.).

---

## 1. The gap

Conformal prediction can certify that an interval has nominal coverage; selective prediction can
trade coverage for accuracy by abstaining. Neither can usually show whether a model **abstains in
the right place** — real tasks carry no ground truth for *which points were ever recoverable*. So
"the model is well-calibrated and abstains on 30% of names" is unfalsifiable as a claim about
*whether those were the right 30%*.

This project builds a regression task that **does** carry that ground truth and uses it to
mechanism-validate the selective layer. The demonstration domain is cross-sectional reconstruction
of a systematic manager's portfolio **weights** from public features — a supervised regression
whose irreducible-noise floor (~60% proprietary) is *known by construction*, not assumed. That is
the differentiator from the crowded returns/ranking conformal-for-trading setting (e.g. "When Alpha
Breaks", 2026): the **allocation target + known-floor mechanism check** is what no prior work has.

## 2. Substrate (layered, public-primary)

- **Layer 1a — known-ceiling semi-synthetic (the controlled experiment).** A transparent public
  allocator `w = base(cap-diversified) × momentum_tilt(public features) + λ·hidden_overlay + ε`,
  where the overlay is a seeded function the learner is **not** given (the analogue of the
  proprietary score) and `ε` is irreducible noise. We therefore know, per name, the recoverable
  fraction and the irreducible-noise magnitude — the only way to test the mechanism. Tuned so the
  public-recoverable R² ≈ 0.40 (a deliberately hard but non-trivial recoverable fraction), for
  face validity against realistic allocation-reconstruction tasks.
- **Layer 1b — real public task (external validity).** 21-day cross-sectional forward returns from
  the same PIT panel, with a real train-calm → test-drawdown split — guards against a
  self-fulfilling synthetic.
- **Layer 2 — real-data confirm (private).** The identical pipeline was also run on a genuine
  real-data reconstruction task held in a separate private repository; referenced here by pointer
  only (§5). No private data, numbers, or provenance enter this repo.

## 3. Method (all public-feature-only; knobs frozen before the method ran)

Base learners (LightGBM mean + pinball quantiles) → **CQR** heteroscedastic intervals
(Romano 2019) → **Mondrian / group-conditional** calibration (per momentum decile) → **group-
conditional Adaptive Conformal Inference** (Gibbs–Candès 2021) as the shift-robust headline →
**weighted/covariate-shift CQR** (Tibshirani 2019) as an ablation. The **selective** layer abstains
on a **per-name calibration-residual scale** `u_i` (shrunk MAD of the name's own calibration
residuals): if the irreducible component is name-persistent, a name's own historical error scale is
a PIT-legal proxy for its irreducible noise — exactly the signal that raw interval width misses.

## 4. Pre-registered gates and what they returned (Layer 1a, multi-seed {0,1,2})

Gate-first: the ship/reject statistics were frozen in
[`p2_method_preregistration.md`](p2_method_preregistration.md) **before** the method ran; no knob
was tuned post-hoc. Full numbers in [`p2_method_results.md`](p2_method_results.md).

| Gate | What it tests | Result |
|---|---|---|
| **G-PRIMARY (i)** | selective abstention beats random on retained error | **PASS** — retained-MAE cut 0.178 ≥ Δ=0.119 @70%, ~75% of the oracle's headroom |
| **G-PRIMARY (ii)** | conditional coverage on the retained set | conditioned axes within τ=5pp (cap_tier 0.034, mom_decile 0.032); **sector ~1pp over** (qualified) |
| **G-SHIFT** | worst-group coverage under the drawdown | **PASS** — group-conditional ACI worst-group 0.507 → **0.815**; shift coverage 0.58 → 0.87 |
| **G-MECHANISM** | abstention coincides with the *known* floor | **PASS** — AUC(−u → recoverable) 0.81, ρ(u, σ_irr) 0.86, **survives a vol_63 confound control** |
| **G-NULL** | label-shuffle leakage guard | **PASS** — selective advantage collapses 0.178 → 0.002 |

Three figures (`figures/`, generated by `src/figures.py`):

- **`fig1_risk_coverage.png`** — the per-name score (blue) nearly matches the noise-aware **oracle**
  (green), both far below random (grey): abstention is *useful*, not cosmetic.
- **`fig2_coverage_shift.png`** — under the drawdown, naive split-conformal collapses (worst-group
  0.48) while **group-conditional ACI holds** (worst-group 0.79). Mondrian-alone does *not* help
  (the shift is temporal, not static-group) — a clean ablation isolating the online layer as the
  active ingredient.
- **`fig3_mechanism.png`** — `u_i` rises monotonically with the *known* injected floor σ_irr
  (ρ=0.89); recoverable names cluster low-left, bespoke names high-right. **This is the headline:
  the abstention lands in the provably-right place.**

**Layer 1b (real returns).** G-SHIFT replicates — ACI lifts worst-group 0.734 → 0.858 and holds
shift coverage at nominal on genuine forward returns; the selective gain is real but weaker (returns
are closer to a martingale than the allocator). So the shift story is not a synthetic artifact.

## 5. Layer-2 real-data confirm — private, by pointer

The identical pipeline (knobs frozen) was also run on a genuine real-data reconstruction task held
in a **separate private repository**. Qualitatively, the per-name selective ranking and the online
marginal-coverage restoration transferred, and the conditional-coverage guarantee is confirmed to be
**group-conditional and substrate-dependent** rather than universal. No private data, numbers, or
provenance are reproduced here by design — the mechanism *validation* lives in Layer 1a, where
ground truth exists.

## 6. Honest boundaries

- **No distribution-free exact conditional coverage** — forbidden by the impossibility result
  (Foygel Barber et al. 2021). The guarantee is **group-conditional / approximate-and-validated**,
  stated as such; the un-conditioned-axis miss (G-PRIMARY ii, sector) is the visible edge of that
  boundary, logged as a deferred multi-dimensional-Mondrian extension rather than tuned away.
- **No alpha, no backtested return, no trading claim** — this is a UQ method, demonstrated on an
  allocation-reconstruction regression. The mechanism is validated, not a P&L.
